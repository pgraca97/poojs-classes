# POO JS - Fichas Práticas

Soluções das fichas práticas de Programação Orientada a Objetos em JavaScript - ESMAD, TSIW, 2.º semestre.

| Ficha | Tema | Conceitos-chave |
|-------|------|-----------------|
| [F00](F00_Revisão%20Diagnóstica/) | Revisão Diagnóstica | `const`/`let`, `typeof`, `toFixed`, `forEach`, `filter`, `reduce`, DOM básico |
| [F01](F01_Funções%20e%20Objetos/) | Funções e Objetos | arrow functions, objetos literais, `this`, `for...in`/`for...of`, `reduce`, rest params |
| [F02](F02_Métodos%20de%20Array/) | Métodos de Array | `filter`, `map`, `find`/`findIndex`, `sort`, encadeamento de métodos |
| [F03](F03_DOM%20e%20Eventos/) | DOM e Eventos | `querySelector`, `innerHTML`, `addEventListener`, delegação de eventos, formulários |
| [F04](F04_Classes%20e%20Heran%C3%A7a/) | Classes e Herança | classes, campos privados `#`, getters/setters, métodos estáticos, `extends`, `super` |
| [F05](F05_Soundbase%20Render/) | Renderização Dinâmica | template strings, delegação de eventos, `toSorted`, `localeCompare`, `target`/`currentTarget` |

## Como usar

1. Abrir a pasta da ficha no VS Code.
2. Clicar com o botão direito no `index.html` e escolher "Open with Live Server".
3. Abrir as ferramentas de desenvolvimento (F12) e ir ao separador **Console** para ver o output.
4. As fichas F02 e F03 incluem um `soundbase-dados.js` que é carregado antes do `script.js` - já está configurado no `index.html`.
